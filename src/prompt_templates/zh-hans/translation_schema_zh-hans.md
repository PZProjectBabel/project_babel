下列格式为强制规则, 优先级高于常规中文习惯. 命中类别时必须套用对应格式; 禁止自造格式; 禁止臆造原文不存在的信息; 括号项按原文实际信息增减, 可省略.

【本条必须严格遵守】标点/空格: 译文必须用英文半角标点; 仅允许中文顿号、, 省略号..., 书名号《》例外. 禁用全角逗号、句号、冒号、问号、感叹号、括号、引号. 省略号统一为..., 禁止……和…. , . ? ! : ; 后必须有且仅有1个空格, 文末除外; 其前禁止空格. ...按整体处理, 后接连续语句时不强制空格. ( 前必须有且仅有1个空格, 行首除外; ( 后禁止空格. ) 前禁止空格; ) 后接普通文本时必须有且仅有1个空格; ) 后接标点或文末时禁止空格. 必须删除冗余空格: 连续空格压为1个, 删除行首行尾空格、标点前空格、( 后空格、) 前空格、) 与后续标点间空格. 例: .308子弹 (整盒) / 我不愿承认, 但确实喜欢...可现在那些都不重要了. 一切已经太迟了! 不是吗?

【本条必须严格遵守】物品: 必须用 物品名称 (颜色, 品质, 描述1, ..., 描述n). 例: T恤 (蓝), 条纹T恤 (蓝底白纹), 格子衬衫 (红底白格), 连帽衫 (金), 牛仔裤 (黑), 军用长裤 (沙漠迷彩), 军用长裤 (白色迷彩). 迷彩=颜色. 白色迷彩T恤必须译为T恤 (白色迷彩), 禁止译为迷彩T恤 (白). 特别注意, 服装名称表示方位/部位的属于属于表述，必须放入括号, 例如 军用枪套 (UCP迷彩, 左胯), 军用护腿 (右), 腰包 (前)

【本条必须严格遵守】液体容器/炊具: 必须用 容器 (内容物, 描述1, ..., 描述n). 例: 塑料瓶 (葡萄酒), 蒸煮锅 (意大利面), 汽油罐 (空).

【本条必须严格遵守】包装量词: 盒装、箱装、袋装等必须用整X. 格式: 物品 (包装形式1, 包装形式2, 状态). 单一包装用整X. 例: .308子弹 (整盒), .308子弹 (整箱), 瓶装水 (整箱), 啤酒 (瓶装, 整箱), 啤酒 (罐装, 整箱), 牛奶 (盒装, 整箱), 牛奶 (袋装, 整箱).

颜色: 颜色词尽量入括号, 一般不带色字, 迷彩除外. 标准: (黑), (蓝), (棕), (青), (绿), (灰), (红), (紫), (黄), (橙), (粉), (金), (银), (浅蓝), (浅棕), (米黄), (绿色迷彩), (灰色迷彩), (沙漠迷彩), (白色迷彩), (透明).

连字符-: 英文物品名用-区分颜色/材质/形态时, 必须改为括号格式. 例: 军用长裤 - 沙漠迷彩=>军用长裤 (沙漠迷彩).

原版枪械: 必须用 枪械型号+枪械种类, 中间无空格. 种类仅用手枪、左轮手枪、自动步枪、半自动步枪、狙击步枪、霰弹枪. 例: M9手枪, M36左轮手枪, M14自动步枪, M16自动步枪, M788狙击步枪, JS-2000霰弹枪.

模组枪械: 必须用 枪械品牌(如有)+枪械型号+枪械种类, 型号和种类间无空格. 例: 伯莱塔92FS手枪, 格洛克17手枪, 史密斯-韦森M36左轮手枪, 柯尔特蟒蛇左轮手枪, 黑克勒-科赫MP5冲锋枪, 柯尔特M16自动步枪, 雷明顿788狙击步枪 (锯短), 鲁格M77/22步枪, 春田M1加兰德半步枪, 赫斯塔尔FAL自动步枪, 萨科M60通用机枪, 英格拉姆MAC-10冲锋枪, 莫斯伯格500霰弹枪 (锯短), 伊萨卡37霰弹枪, 弗兰齐SPAS-12霰弹枪, 马林1894步枪. 春田M1加兰德半步枪禁止译为斯普林菲尔德M1加兰德半步枪.

原版弹匣: 优先用 枪械型号+枪械类型+弹匣; 未注明适配枪械则用 尺寸+弹匣. 例: B-F手枪弹匣, 5.56mm弹匣.

模组弹匣: 优先用 枪械品牌(如有)+枪械型号+枪械类型+弹匣; 未注明适配枪械则用 尺寸+弹匣. 目的: 名称排序时枪械和弹匣相邻. 例: 格洛克17手枪弹匣, 黑克勒-科赫MP5冲锋枪弹匣, AK-47自动步枪弹匣.

模组枪械配件: 专用配件优先用 枪械品牌(如有)+枪械型号+枪械类型+枪械配件. 目的: 名称排序时枪械和配件相邻. 例: 黑克勒-科赫MP5冲锋枪延长枪托.

子弹: 优先用 尺寸+子弹; 有型号后缀则用 尺寸+空格+型号后缀+子弹; 必要时加括号说明. 例: .22子弹, .22 ACP子弹, .44 MAG子弹, 9mm子弹, 5.56x45mm子弹, 7.62x39mm子弹 (整盒), 7.62x39mm子弹 (整箱).

消音器: 必须用 尺寸+空格+后缀+消音器; 无后缀用 尺寸+消音器. 例: .308/7.62mm消音器, .22 LR消音器, 5.56mm消音器.

车辆: 优先用 年代+品牌+型号+特殊说明; 原文注明车型时用 年代+品牌+型号+特殊说明+车型. 例: 92款福特维多利亚皇冠警用版, 92款奥什科什M911军用半挂卡车, 90款福特F350救护车, 德伦巴厢式货车.

以上的【基本规则】和【翻译规则】必须遵守。
