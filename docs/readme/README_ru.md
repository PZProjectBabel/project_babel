## Установка и использование

Руководство для игроков, желающих использовать пакет перевода в игре.

1. Перейдите на страницу Steam Workshop: [[B42]ProjectBabel](https://steamcommunity.com/sharedfiles/filedetails/?id=3759583822)
2. Нажмите «Подписаться».
3. Запустите игру, включите этот мод перевода в меню «Моды».
4. Текст перевода из модов, загруженных позже, переопределяет более ранние, поэтому этот мод перевода должен загружаться после игровых модов.
5. Наслаждайтесь!

## Инструменты и структура каталогов (для разработчиков)

Этот раздел предназначен для разработчиков, желающих понять внутреннее устройство автоматизации проекта.

### Каталоги проекта

| Каталог | Описание |
|------|------|
| `src/` | Исходный код конвейера перевода .NET 10, 15 модулей |
| `config/` | Конфигурация конвейера (LLM, Steam, параметры RAG и др.) |
| `data/` | Данные времени выполнения: метаданные модов, эмбеддинги, кэш переводов |
| `translation_ref/` | Эталонные переводы как контекст LLM |
| `base_game_keys/` | Ключи перевода базовой игры для дедупликации |
| `final_outputs/` | Итоговый вывод перевода в формате мода PZ |
| `docs/` | Документация: прогресс, участие, спецификации конвейера |
| `temp/` | Временные файлы конвейера |
| `src/prompt_templates/` | Шаблоны промптов LLM |

### Модули конвейера (порядок выполнения)

| Шаг | Модуль | Функция |
|------|------|------|
| 1 | `ConfigReader` | Загрузка конфигурации/секретов/языков |
| 2 | `RepoDataLoader` | Загрузка эталонов и кэша переводов |
| 3 | `ModIdCollector` | Сбор ID модов Workshop |
| 4 | `ModInfoFetcher` | Получение метаданных Steam |
| 5 | `ModDownloader` | Загрузка модов через steamcmd |
| 6 | `ContentExtractor` | Разбор файлов перевода модов → `TranslationEntry` |
| 7 | `ContentChecker` | Проверка безопасности контента |
| 8 | `EmbeddingFetcher` | Вычисление векторов эмбеддингов текста |
| 9 | `TranslationBatcher` | Создание пакетов перевода |
| 10 | `RagContextRetriever` | Извлечение контекстов RAG |
| 11 | `LLMTranslator` | Выполнение перевода LLM |
| 12 | `ResultWriter` | Запись в data/ и translation_ref/ |
| 13 | `FinalOutputWriter` | Генерация итогового вывода в формате мода PZ |
| 14 | `ProgressReporter` | Генерация отчетов о прогрессе |

### Технологический стек

- **Язык**: C# (.NET 10)
- **Целевая платформа**: GitHub Actions Linux x64 runner
- **Тесты**: xUnit (Windows x64)
- **LLM**: DeepSeek API (настраивается)
- **Embedding**: Векторизация текста для поиска сходства RAG
- **Проверка контента**: Многоуровневая проверка безопасности на основе LLM

Подробная техническая документация: [Конвейер TranslationEntry](../pipeline/translation_entry_pipeline_ru.md)
