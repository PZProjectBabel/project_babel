## Как установить и использовать

Это руководство для игроков, желающих напрямую использовать этот переводчик в игре.

1.  Перейдите на нашу страницу в Steam Workshop: [[B42]Project Babel](https://steamcommunity.com/sharedfiles/filedetails/?id=3759583822)
2.  Нажмите кнопку «Подписаться».
3.  Запустите игру и включите этот мод перевода в меню «Моды» в главном меню.
4.  Перевод текстов модов, включенных позже, имеет приоритет над текстами включенных раньше, поэтому этот мод перевода должен быть включен после функциональных модов (по возможности внизу списка).
5.  Наслаждайтесь игрой!

## Инструменты и структура каталогов (для разработчиков)

Этот раздел предназначен для разработчиков, желающих понять принципы автоматизации проекта.

### Каталоги проекта

| Каталог | Описание |
|------|------|
| `src/` | Исходный код конвейера перевода .NET 10, включающий 15 модулей + 2 независимых модуля |
| `config/` | Конфигурационные файлы конвейера (LLM, Steam, параметры RAG и т.д.) |
| `data/` | Данные времени выполнения: метаданные модов, эмбеддинги, кэш переводов |
| `translation_ref/` | Эталонные данные переводов (например, авторизованные моды от «如一汉化组» (As1)), предоставляющие LLM референсы для перевода |
| `base_game_keys/` | Ключи переводов базовой игры, используемые для дедупликации, чтобы не перезаписывать оригинальный текст |
| `final_outputs/` | Финальные выходные данные: пакет мода `project_babel/`, иконки `icons/` и описания мастерской `workshop_descriptions/` |
| `docs/` | Документация проекта: отчеты о прогрессе, руководства по участию, описание конвейера |
| `temp/` | Временные файлы конвейера (отдельный каталог для каждого запуска) |
| `src/prompt_templates/` | Шаблоны подсказок LLM (перевод/проверка содержимого) |

### Модули конвейера (в порядке выполнения)

| Шаг | Модуль | Функция |
|------|------|------|
| 1 | `ConfigReader` | Загрузка конфигурации/ключей/списка языков |
| 2 | `RepoDataLoader` | Загрузка эталонных переводов и кэша переводов |
| 3 | `ModIdCollector` | Сбор ID модов Workshop |
| 4 | `ModInfoFetcher` | Получение метаданных Steam |
| 5 | `SteamCmdBootstrapper` | Подготовка среды выполнения steamcmd для текущей платформы |
| 6 | `ModDownloader` | Загрузка модов через steamcmd |
| 7 | `ContentExtractor` | Разбор файлов перевода модов → `TranslationEntry` |
| 8 | `ContentChecker` | Проверка безопасности контента (наркотики/порнография/насилие) |
| 9 | `EmbeddingFetcher` | Вычисление векторов embedding текста |
| 10 | `TranslationBatcher` | Создание пакетов перевода, не зависящих от языка |
| 11 | `RagContextRetriever` | Поиск контекста RAG (точные ключи + сходство embedding) |
| 12 | `LLMTranslator` | Вызов LLM для выполнения перевода |
| 13 | `ResultWriter` | Запись в data/ и translation_ref/ |
| 14 | `FinalOutputWriter` | Генерация итогового вывода в формате мода PZ |
| 15 | `ProgressReporter` | Генерация отчёта о прогрессе |

### Независимые модули

| Модуль | Функция |
|------|------|
| `WorkshopMonitor` | Регулярно извлекает новые моды из Steam Workshop, фильтрует по количеству подписок и добавляет в `request_for_translation.txt` |
| `DocGenerator` | Многоязычный генератор документации на основе LLM |

### Технический стек

- **Язык**: C# (.NET 10)
- **Целевая платформа**: GitHub Actions Linux x64 runner
- **Тестирование**: xUnit (Windows x64)
- **LLM**: DeepSeek API (настраиваемый)
- **Embedding**: Векторизация текста для поиска по сходству RAG
- **Проверка контента**: Многоуровневая проверка безопасности на основе LLM

Подробный [технический справочник](./docs/technical_reference/technical_reference_ru.md).
