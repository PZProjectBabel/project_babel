## วิธีการติดตั้งและการใช้งาน

นี่คือคำแนะนำสำหรับผู้เล่นที่ต้องการใช้โครงการแปลภาษาในเกมโดยตรง

1.  ไปที่หน้า Steam Workshop ของเรา: [[B42]Project Babel](https://steamcommunity.com/sharedfiles/filedetails/?id=3759583822)
2.  คลิกปุ่ม "สมัครสมาชิก"
3.  เริ่มเกม ไปที่เมนูหลักของเกม เลือกการจัดการ "Mods" และเปิดใช้งาน Mod แปลภาษานี้
4.  ข้อความแปลของ Mod ที่เปิดใช้งานทีหลังจะทับข้อความของ Mod ที่เปิดใช้งานก่อน ดังนั้น Mod แปลภาษานี้ควรเปิดใช้งานหลังจาก Mod ฟังก์ชัน (วางไว้ด้านล่างสุดถ้าเป็นไปได้)
5.  สนุกกับเกม!

## วิธีการมีส่วนร่วม

เรายินดีต้อนรับทุกคนที่ต้องการมีส่วนร่วม ไม่ว่าจะเป็นการแก้ไขข้อผิดพลาด เพิ่มฟังก์ชันใหม่ เขียนเทมเพลตพร้อมท์ หรือให้คำแปลอ้างอิง!

การเรียกใช้ API ของ LLM เพื่อแปลภาษาจำเป็นต้องชำระค่าโทเค็น เพื่อให้โครงการดำเนินไปอย่างเสถียรในระยะยาว หวังว่าคุณจะช่วยเหลือเราอย่างใจกว้าง!

## เครื่องมือและโครงสร้างไดเร็กทอรี (สำหรับนักพัฒนา)

ส่วนนี้เหมาะสำหรับนักพัฒนาที่ต้องการเข้าใจหลักการทำงานอัตโนมัติของโครงการ

### ไดเร็กทอรีโครงการ

| ไดเรกทอรี | คำอธิบาย |
|------|------|
| `src/` | ซอร์สโค้ดของไปป์ไลน์การแปล .NET 10 ประกอบด้วย 15 โมดูล |
| `config/` | ไฟล์คอนฟิกของไปป์ไลน์ (พารามิเตอร์ LLM, Steam, RAG ฯลฯ) |
| `data/` | ข้อมูลรันไทม์: เมทาดาทาของ Mod, embedding, แคชการแปล |
| `translation_ref/` | ข้อมูลอ้างอิงการแปล (เช่น Mod ที่ได้รับอนุญาตจากทีม As1) เพื่อให้ LLM ใช้เป็นข้อมูลอ้างอิงการแปล |
| `base_game_keys/` | คีย์การแปลของเกมหลัก ใช้เพื่อป้องกันการทับข้อความต้นฉบับ |
| `final_outputs/` | ผลลัพธ์สุดท้าย: แพ็ค Mod `project_babel/`, ไอคอน `icons/` และคำอธิบาย Workshop `workshop_descriptions/` |
| `docs/` | เอกสารโครงการ: รายงานความคืบหน้า, คู่มือการมีส่วนร่วม, คำอธิบายไปป์ไลน์ |
| `temp/` | ไฟล์ชั่วคราวของไปป์ไลน์ (ไดเรกทอรีแยกในแต่ละครั้งที่รัน) |
| `src/prompt_templates/` | เทมเพลตพร้อมท์ของ LLM (การแปล/การตรวจสอบเนื้อหา) |

### โมดูลไปป์ไลน์ (ตามลำดับการทำงาน)

| ขั้นตอน | โมดูล | ฟังก์ชัน |
|------|------|------|
| 1 | `ConfigReader` | โหลดการตั้งค่า/คีย์/รายการภาษา |
| 2 | `RepoDataLoader` | โหลดการแปลอ้างอิงและแคชการแปล |
| 3 | `ModIdCollector` | รวบรวม ID โมดูล Workshop |
| 4 | `ModInfoFetcher` | ดึงข้อมูลเมตาของ Steam |
| 5 | `SteamCmdBootstrapper` | เตรียมรันไทม์ steamcmd สำหรับแพลตฟอร์มปัจจุบัน |
| 6 | `ModDownloader` | ดาวน์โหลดโมดูลผ่าน steamcmd |
| 7 | `ContentExtractor` | แยกวิเคราะห์ไฟล์แปลโมดูล → `TranslationEntry` |
| 8 | `ContentChecker` | ตรวจสอบความปลอดภัยของเนื้อหา (ยาเสพติด/สื่อลามก/ความรุนแรง) |
| 9 | `EmbeddingFetcher` | คำนวณเวกเตอร์ embedding ของข้อความ |
| 10 | `TranslationBatcher` | สร้างชุดการแปลที่ไม่ขึ้นกับภาษาเป้าหมาย |
| 11 | `RagContextRetriever` | ดึงบริบท RAG (คีย์ที่แน่นอน + ความคล้ายคลึงของ embedding) |
| 12 | `LLMTranslator` | เรียก LLM เพื่อดำเนินการแปล |
| 13 | `ResultWriter` | เขียนไปยัง data/ และ translation_ref/ |
| 14 | `FinalOutputWriter` | สร้างผลลัพธ์รูปแบบโมดูล PZ สุดท้าย |
| 15 | `ProgressReporter` | สร้างรายงานความคืบหน้า |

### เทคโนโลยี่ที่ใช้

- **ภาษา**: C# (.NET 10)
- **แพลตฟอร์มเป้าหมาย**: GitHub Actions Linux x64 runner
- **การทดสอบ**: xUnit (Windows x64)
- **LLM**: DeepSeek API (ปรับแต่งได้)
- **Embedding**: การทำข้อความเป็นเวกเตอร์เพื่อใช้ในการค้นหาความคล้ายคลึงของ RAG
- **การตรวจสอบเนื้อหา**: การตรวจสอบความปลอดภัยหลายระดับที่ขับเคลื่อนโดย LLM
