## การติดตั้งและการใช้งาน

คำแนะนำสำหรับผู้เล่นที่ต้องการใช้แพ็คแปลในเกม

1. ไปที่หน้า Steam Workshop: [[B42]ProjectBabel](https://steamcommunity.com/sharedfiles/filedetails/?id=3759583822)
2. คลิก "สมัครสมาชิก"
3. เปิดเกม เปิดใช้งานม็อดแปลนี้ในเมนู Mods
4. ข้อความแปลจากม็อดที่โหลดทีหลังจะแทนที่อันก่อนหน้า ดังนั้นม็อดแปลนี้ต้องโหลดหลังจากม็อดเกมเพลย์
5. ขอให้สนุก!

## เครื่องมือและโครงสร้างไดเรกทอรี (สำหรับนักพัฒนา)

ส่วนนี้สำหรับนักพัฒนาที่ต้องการเข้าใจการทำงานภายในของระบบอัตโนมัติของโครงการ

### ไดเรกทอรีโครงการ

| ไดเรกทอรี | คำอธิบาย |
|------|------|
| `src/` | ซอร์สโค้ดไปป์ไลน์แปลภาษา .NET 10, 15 โมดูล |
| `config/` | การกำหนดค่าไปป์ไลน์ (LLM, Steam, พารามิเตอร์ RAG ฯลฯ) |
| `data/` | ข้อมูลรันไทม์: เมทาดาทาม็อด, การฝัง, แคชการแปล |
| `translation_ref/` | การแปลอ้างอิงเป็นบริบท LLM |
| `base_game_keys/` | คีย์การแปลเกมพื้นฐานสำหรับการขจัดรายการซ้ำ |
| `final_outputs/` | เอาต์พุตสุดท้ายในรูปแบบม็อด PZ |
| `docs/` | เอกสาร: ความคืบหน้า, การมีส่วนร่วม, ข้อมูลจำเพาะไปป์ไลน์ |
| `temp/` | ไฟล์ชั่วคราวของไปป์ไลน์ |
| `src/prompt_templates/` | เทมเพลตพรอมต์ LLM |

### โมดูลไปป์ไลน์ (ลำดับการทำงาน)

| ขั้นตอน | โมดูล | ฟังก์ชัน |
|------|------|------|
| 1 | `ConfigReader` | โหลดการกำหนดค่า/ความลับ/ภาษา |
| 2 | `RepoDataLoader` | โหลดข้อมูลอ้างอิงและแคชการแปล |
| 3 | `ModIdCollector` | รวบรวม ID ม็อด Workshop |
| 4 | `ModInfoFetcher` | ดึงเมทาดาทา Steam |
| 5 | `ModDownloader` | ดาวน์โหลดม็อดผ่าน steamcmd |
| 6 | `ContentExtractor` | วิเคราะห์ไฟล์แปลม็อด → `TranslationEntry` |
| 7 | `ContentChecker` | ตรวจสอบความปลอดภัยของเนื้อหา |
| 8 | `EmbeddingFetcher` | คำนวณเวกเตอร์การฝังข้อความ |
| 9 | `TranslationBatcher` | สร้างชุดการแปล |
| 10 | `RagContextRetriever` | ดึงบริบท RAG |
| 11 | `LLMTranslator` | ดำเนินการแปล LLM |
| 12 | `ResultWriter` | เขียนไปยัง data/ และ translation_ref/ |
| 13 | `FinalOutputWriter` | สร้างเอาต์พุตสุดท้ายในรูปแบบม็อด PZ |
| 14 | `ProgressReporter` | สร้างรายงานความคืบหน้า |

### สแตกเทคโนโลยี

- **ภาษา**: C# (.NET 10)
- **แพลตฟอร์มเป้าหมาย**: GitHub Actions Linux x64 runner
- **การทดสอบ**: xUnit (Windows x64)
- **LLM**: DeepSeek API (กำหนดค่าได้)
- **Embedding**: การทำเวกเตอร์ข้อความสำหรับการค้นหาความคล้ายคลึง RAG
- **การตรวจสอบเนื้อหา**: การตรวจสอบความปลอดภัยหลายระดับที่ขับเคลื่อนด้วย LLM

เอกสารทางเทคนิคโดยละเอียด: [ไปป์ไลน์ TranslationEntry](../pipeline/translation_entry_pipeline_th.md)
