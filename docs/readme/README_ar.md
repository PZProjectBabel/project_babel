## كيفية التثبيت والاستخدام

هذا دليل للاعبين الذين يرغبون في استخدام حزمة الترجمة داخل اللعبة.

1. انتقل إلى صفحة Steam Workshop: [[B42]ProjectBabel](https://steamcommunity.com/sharedfiles/filedetails/?id=3759583822)
2. انقر على زر "اشتراك".
3. شغّل اللعبة، وفعّل مود الترجمة هذا في قائمة "Mods".
4. نصوص الترجمة من المودات المحملة لاحقًا تتجاوز المودات السابقة، لذا يجب تحميل مود الترجمة هذا بعد مودات اللعب.
5. استمتع!

## الأدوات وهيكل الدليل (للمطورين)

هذا القسم موجه للمطورين الذين يرغبون في فهم آلية أتمتة المشروع.

### أدلة المشروع

| الدليل | الوصف |
|------|------|
| `src/` | كود مصدر خط أنابيب الترجمة .NET 10، 15 وحدة |
| `config/` | إعدادات خط الأنابيب (LLM، Steam، معاملات RAG إلخ) |
| `data/` | بيانات وقت التشغيل: بيانات التعريف، التضمينات، ذاكرة التخزين المؤقت |
| `translation_ref/` | ترجمات مرجعية كسياق LLM |
| `base_game_keys/` | مفاتيح ترجمة اللعبة الأساسية لإزالة التكرار |
| `final_outputs/` | مخرجات الترجمة النهائية بتنسيق مود PZ |
| `docs/` | الوثائق: التقدم، المساهمة، مواصفات خط الأنابيب |
| `temp/` | ملفات مؤقتة لخط الأنابيب |
| `src/prompt_templates/` | قوالب مطالبات LLM |

### وحدات خط الأنابيب (ترتيب التنفيذ)

| الخطوة | الوحدة | الوظيفة |
|------|------|------|
| 1 | `ConfigReader` | تحميل الإعدادات/الأسرار/اللغات |
| 2 | `RepoDataLoader` | تحميل المراجع وذاكرة التخزين المؤقت |
| 3 | `ModIdCollector` | جمع معرّفات مودات Workshop |
| 4 | `ModInfoFetcher` | جلب بيانات Steam الوصفية |
| 5 | `ModDownloader` | تنزيل المودات عبر steamcmd |
| 6 | `ContentExtractor` | تحليل ملفات الترجمة ← `TranslationEntry` |
| 7 | `ContentChecker` | مراجعة سلامة المحتوى |
| 8 | `EmbeddingFetcher` | حساب متجهات التضمين النصي |
| 9 | `TranslationBatcher` | إنشاء دفعات الترجمة |
| 10 | `RagContextRetriever` | استرجاع سياقات RAG |
| 11 | `LLMTranslator` | تنفيذ ترجمة LLM |
| 12 | `ResultWriter` | الكتابة إلى data/ و translation_ref/ |
| 13 | `FinalOutputWriter` | إنشاء المخرجات النهائية بتنسيق مود PZ |
| 14 | `ProgressReporter` | إنشاء تقارير التقدم |

### المجموعة التقنية

- **اللغة**: C# (.NET 10)
- **المنصة المستهدفة**: GitHub Actions Linux x64 runner
- **الاختبارات**: xUnit (Windows x64)
- **LLM**: DeepSeek API (قابل للتكوين)
- **Embedding**: تحويل النص إلى متجهات لاسترجاع التشابه RAG
- **مراجعة المحتوى**: مراجعة أمان متعددة المستويات مدعومة بـ LLM

وثائق تقنية مفصلة: [خط أنابيب TranslationEntry](../pipeline/translation_entry_pipeline_ar.md)
