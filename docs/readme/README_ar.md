## كيفية التثبيت والاستخدام

هذا هو الدليل للاعبين الذين يرغبون في استخدام مشروع الترجمة هذا مباشرة في اللعبة.

1.  اذهب إلى صفحة ورشة عمل Steam الخاصة بنا: [[B42]Project Babel](https://steamcommunity.com/sharedfiles/filedetails/?id=3759583822)
2.  انقر على زر "الاشتراك".
3.  ابدأ اللعبة، وقم بتمكين هذه الترجمة في إدارة "المودات" من القائمة الرئيسية.
4.  نصوص الترجمة من المودات التي تم تمكينها لاحقًا تحل محل تلك التي تم تمكينها مبكرًا، لذا يجب تمكين هذه الترجمة بعد المودات الوظيفية (في الأسفل قدر الإمكان).
5.  استمتع باللعبة!

## الأدوات وهيكل الدليل (للمطورين)

هذا القسم موجه للمطورين الذين يرغبون في فهم مبادئ أتمتة المشروع.

### دليل المشروع

| الدليل | الوصف |
|------|------|
| `src/` | .NET 10 كود مصدر خط أنابيب الترجمة، يحتوي على 15 وحدة + وحدتين مستقلتين |
| `config/` | ملفات تكوين خط الأنابيب (معلمات LLM، Steam، RAG إلخ) |
| `data/` | بيانات وقت التشغيل: بيانات وصفية للمودات، توزيعات (embeddings)، ذاكرة تخزين مؤقت للترجمة |
| `translation_ref/` | بيانات الترجمة المرجعية (مثل مودات مرخصة من مجموعة As1)، توفر مرجعًا للترجمة لـ LLM |
| `base_game_keys/` | مفاتيح ترجمة اللعبة الأساسية، تستخدم لإزالة التكرار ومنع الكتابة فوق النص الأصلي |
| `final_outputs/` | المخرجات النهائية: حزمة المود `project_babel/`، وأيقونات `icons/` وأوصاف ورشة العمل `workshop_descriptions/` |
| `docs/` | وثائق المشروع: تقارير التقدم، دليل المساهمة، شرح خط الأنابيب |
| `temp/` | ملفات مؤقتة لخط الأنابيب (دليل مستقل لكل تشغيل) |
| `src/prompt_templates/` | قوالب التعليمات لـ LLM (الترجمة/مراجعة المحتوى) |

### وحدات خط الأنابيب (حسب ترتيب التنفيذ)

| الخطوة | الوحدة | الوظيفة |
|------|------|------|
| 1 | `ConfigReader` | تحميل التهيئة/المفاتيح/قائمة اللغات |
| 2 | `RepoDataLoader` | تحميل الترجمات المرجعية وذاكرة الترجمة المؤقتة |
| 3 | `ModIdCollector` | جمع معرفات التعديلات من ورشة العمل |
| 4 | `ModInfoFetcher` | الحصول على بيانات Steam الوصفية |
| 5 | `SteamCmdBootstrapper` | تجهيز بيئة تشغيل steamcmd للنظام الحالي |
| 6 | `ModDownloader` | تنزيل التعديلات عبر steamcmd |
| 7 | `ContentExtractor` | تحليل ملفات ترجمة التعديل → `TranslationEntry` |
| 8 | `ContentChecker` | فحص أمان المحتوى (مخدرات/إباحية/عنف) |
| 9 | `EmbeddingFetcher` | حساب متجهات التضمين النصي |
| 10 | `TranslationBatcher` | إنشاء دفعات ترجمة مستقلة عن اللغة الهدف |
| 11 | `RagContextRetriever` | استرجاع سياق RAG (المفاتيح الدقيقة + تشابه التضمين) |
| 12 | `LLMTranslator` | استدعاء LLM لتنفيذ الترجمة |
| 13 | `ResultWriter` | الكتابة إلى data/ و translation_ref/ |
| 14 | `FinalOutputWriter` | إنشاء مخرجات نهائية بتنسيق تعديل PZ |
| 15 | `ProgressReporter` | إنشاء تقرير التقدم |

### الوحدات المستقلة

| الوحدة | الوظيفة |
|------|------|
| `WorkshopMonitor` | جلب دوري للمودات الجديدة من Steam Workshop، التصفية حسب عدد الاشتراكات وإدراجها في `request_for_translation.txt` |
| `DocGenerator` | مولد وثائق متعدد اللغات يعمل بتقنية LLM |

### المكدس التقني

- **اللغة**: C# (.NET 10)
- **المنصة المستهدفة**: GitHub Actions Linux x64 runner
- **الاختبارات**: xUnit (Windows x64)
- **LLM**: DeepSeek API (قابل للتكوين)
- **Embedding**: تحويل النص إلى متجهات للبحث التشابهي RAG
- **فحص المحتوى**: تدقيق أمني متعدد المستويات مدعوم بـ LLM

المزيد من التفاصيل في [المرجع التقني](./docs/technical_reference/technical_reference_ar.md).
