## Встановлення та використання

Посібник для гравців, які хочуть використовувати переклад у грі.

1. Перейдіть на сторінку Steam Workshop: [[B42]ProjectBabel](https://steamcommunity.com/sharedfiles/filedetails/?id=3759583822)
2. Натисніть «Підписатися».
3. Запустіть гру, увімкніть цей мод перекладу в меню «Моди».
4. Текст перекладу з модів, завантажених пізніше, перевизначає попередні, тому цей мод перекладу має завантажуватися після ігрових модів.
5. Насолоджуйтесь!

## Інструменти та структура каталогів (для розробників)

Цей розділ призначений для розробників, які бажають зрозуміти внутрішню автоматизацію проєкту.

### Каталоги проєкту

| Каталог | Опис |
|------|------|
| `src/` | Вихідний код конвеєра перекладу .NET 10, 15 модулів |
| `config/` | Конфігурація конвеєра (LLM, Steam, параметри RAG тощо) |
| `data/` | Дані часу виконання: метадані модів, ембеддинги, кеш перекладів |
| `translation_ref/` | Еталонні переклади як контекст LLM |
| `base_game_keys/` | Ключі перекладу базової гри для дедуплікації |
| `final_outputs/` | Підсумковий вивід перекладу у форматі мода PZ |
| `docs/` | Документація: прогрес, участь, специфікації конвеєра |
| `temp/` | Тимчасові файли конвеєра |
| `src/prompt_templates/` | Шаблони промптів LLM |

### Модулі конвеєра (порядок виконання)

| Крок | Модуль | Функція |
|------|------|------|
| 1 | `ConfigReader` | Завантаження конфігурації/секретів/мов |
| 2 | `RepoDataLoader` | Завантаження еталонів і кешу перекладів |
| 3 | `ModIdCollector` | Збір ID модів Workshop |
| 4 | `ModInfoFetcher` | Отримання метаданих Steam |
| 5 | `ModDownloader` | Завантаження модів через steamcmd |
| 6 | `ContentExtractor` | Розбір файлів перекладу → `TranslationEntry` |
| 7 | `ContentChecker` | Перевірка безпеки контенту |
| 8 | `EmbeddingFetcher` | Обчислення векторів ембеддингів тексту |
| 9 | `TranslationBatcher` | Створення пакетів перекладу |
| 10 | `RagContextRetriever` | Вилучення контекстів RAG |
| 11 | `LLMTranslator` | Виконання перекладу LLM |
| 12 | `ResultWriter` | Запис у data/ та translation_ref/ |
| 13 | `FinalOutputWriter` | Генерація підсумкового виводу у форматі мода PZ |
| 14 | `ProgressReporter` | Генерація звітів про прогрес |

### Технологічний стек

- **Мова**: C# (.NET 10)
- **Цільова платформа**: GitHub Actions Linux x64 runner
- **Тести**: xUnit (Windows x64)
- **LLM**: DeepSeek API (налаштовується)
- **Embedding**: Векторизація тексту для пошуку схожості RAG
- **Перевірка контенту**: Багаторівнева перевірка безпеки на основі LLM

Детальна технічна документація: [Конвеєр TranslationEntry](../pipeline/translation_entry_pipeline_uk.md)
