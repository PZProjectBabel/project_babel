## Як встановити та використовувати

Це посібник для гравців, які хочуть безпосередньо використовувати цей перекладацький проект у грі.

1.  Перейдіть на нашу сторінку Steam Workshop: [[B42]Project Babel](https://steamcommunity.com/sharedfiles/filedetails/?id=3759583822)
2.  Натисніть кнопку «Підписатися».
3.  Запустіть гру, увімкніть цей перекладацький мод у меню «Моди» головного меню.
4.  Текст перекладу модів, увімкнених пізніше, має пріоритет над раніше увімкненими, тому цей перекладацький мод потрібно вмикати після функціональних модів (бажано внизу списку).
5.  Насолоджуйтесь грою!

## Інструменти та структура каталогів (для розробників)

Цей розділ призначений для розробників, які хочуть зрозуміти принципи автоматизації проекту.

### Каталоги проекту

| Каталог | Опис |
|------|------|
| `src/` | Вихідний код конвеєра перекладу .NET 10, що містить 15 модулів |
| `config/` | Файли конфігурації конвеєра (параметри LLM, Steam, RAG тощо) |
| `data/` | Дані часу виконання: метадані модів, вбудовування, кеш перекладу |
| `translation_ref/` | Еталонні дані перекладу (наприклад, авторизовані моди групи As1), що надають LLM довідку для перекладу |
| `base_game_keys/` | Ключі перекладу базової гри, що використовуються для дедуплікації та запобігання перезапису оригінального тексту |
| `final_outputs/` | Кінцевий вихід: пакет модів `project_babel/`, іконки `icons/` та описи майстерні `workshop_descriptions/` |
| `docs/` | Документація проекту: звіти про прогрес, посібник із внеску, опис конвеєра |
| `temp/` | Тимчасові файли конвеєра (окремий каталог для кожного запуску) |
| `src/prompt_templates/` | Шаблони підказок LLM (переклад/перевірка вмісту) |

### Модулі конвеєра (в порядку виконання)

| Крок | Модуль | Функція |
|------|------|------|
| 1 | `ConfigReader` | Завантаження конфігурації/ключів/списку мов |
| 2 | `RepoDataLoader` | Завантаження довідкового перекладу та кешу перекладу |
| 3 | `ModIdCollector` | Збір ідентифікаторів модів Workshop |
| 4 | `ModInfoFetcher` | Отримання метаданих Steam |
| 5 | `SteamCmdBootstrapper` | Підготовка середовища виконання steamcmd для поточної платформи |
| 6 | `ModDownloader` | Завантаження модів через steamcmd |
| 7 | `ContentExtractor` | Розбір файлів перекладу модів → `TranslationEntry` |
| 8 | `ContentChecker` | Перевірка безпеки вмісту (наркотики/порнографія/насильство) |
| 9 | `EmbeddingFetcher` | Обчислення вектора embedding тексту |
| 10 | `TranslationBatcher` | Створення пакетів перекладу, незалежних від цільової мови |
| 11 | `RagContextRetriever` | Пошук контексту RAG (точний ключ + подібність embedding) |
| 12 | `LLMTranslator` | Виклик LLM для виконання перекладу |
| 13 | `ResultWriter` | Запис у data/ та translation_ref/ |
| 14 | `FinalOutputWriter` | Генерація кінцевого виводу у форматі мода PZ |
| 15 | `ProgressReporter` | Генерація звіту про прогрес |

### Технічний стек

- **Мова**: C# (.NET 10)
- **Цільова платформа**: GitHub Actions Linux x64 runner
- **Тестування**: xUnit (Windows x64)
- **LLM**: DeepSeek API (Налаштовується)
- **Embedding**: Векторизація тексту для пошуку подібності RAG
- **Перевірка вмісту**: Багаторівнева перевірка безпеки на основі LLM

Детальний [Технічна довідка](./docs/technical_reference/technical_reference_uk.md).
