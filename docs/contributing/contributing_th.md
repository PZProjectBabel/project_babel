## 1. ก่อนเริ่มต้น

โปรดอ่าน `README.md` ของโปรเจกต์ก่อน เพื่อทำความเข้าใจ:
- เป้าหมายโดยรวมและสถานะปัจจุบันของโปรเจกต์นี้;
- ผู้เล่นทั่วไปสามารถใช้โปรเจกต์นี้ได้อย่างไร (สะดวกสำหรับการทดสอบด้วยตนเอง);
- รายละเอียดทางเทคนิคของโปรเจกต์

## 2. ฉันจะช่วยเหลือได้อย่างไร?

คุณสามารถเลือกมีส่วนร่วมได้หนึ่งหรือหลายวิธีตามความสนใจและทักษะของคุณ:

- ให้กฎการแปลสำหรับภาษาเป้าหมาย
- ให้พจนานุกรมศัพท์เฉพาะทางสำหรับภาษาเป้าหมาย
- ปรับปรุงพรอมต์ของระบบ
- ให้คลังข้อความแปลที่ผ่านการตรวจทานโดยมนุษย์
- ปรับปรุงโมดูลไปป์ไลน์ (.NET) และสคริปต์อัตโนมัติ
- รายงานปัญหา เสนอแนะการปรับปรุง (ระบุใน Issues)
- สนับสนุนทางการเงินสำหรับการเรียกใช้ LLM

ด้านล่างนี้เป็นคำอธิบายเกี่ยวกับสถานการณ์การมีส่วนร่วมหลักๆ

## 3. ให้กฎการแปล พจนานุกรมศัพท์เฉพาะทาง ปรับปรุงพรอมต์ของระบบ

เทมเพลตพรอมต์ของไปป์ไลน์อยู่ที่ `src/prompt_templates/` โดยมีโครงสร้างดังนี้:

- `system_prompt_translate_engine.txt`: พรอมต์ระบบของกลไกการแปลทั่วโลก (ใช้ร่วมกันทุกภาษา);
- `<รหัสภาษา>/translation_dictionary_<รหัสภาษา>.json`: พจนานุกรมศัพท์เฉพาะทางของภาษานั้น;
- `<รหัสภาษา>/translation_schema_<รหัสภาษา>.md`: กฎการแปลและข้อจำกัดด้านรูปแบบของภาษานั้น

ขั้นตอนการมีส่วนร่วม:

1. สร้างไดเรกทอรีย่อยสำหรับภาษาของคุณภายใต้ `src/prompt_templates/` เพิ่มไฟล์พจนานุกรมศัพท์เฉพาะทางและกฎการแปล;
2. หากต้องการปรับเปลี่ยนพฤติกรรมการแปลทั่วโลก ให้แก้ไข `system_prompt_translate_engine.txt` (โปรดทราบว่ามีผลต่อทุกภาษา);
3. ทดสอบในเครื่องเพื่อยืนยันผล;
4. ส่ง PR

## 4. จัดหา corpus การตรวจทานด้วยมนุษย์

หากคุณเป็นผู้สร้าง mod การแปล และยินดีที่จะจัดหา corpora การแปลของคุณเป็นข้อมูลอ้างอิงสำหรับ LLM การแปล โปรดส่งคำขอใน Issues คุณต้องให้ข้อมูลดังต่อไปนี้:

- Mod ID ของ mod การแปลของคุณและภาษาที่แปลเป้าหมาย;
- ภาพหน้าจอของหน้าแบ็คเอนด์ของ mod การแปลของคุณ เพื่อพิสูจน์ว่าคุณเป็นผู้สร้าง mod;
- แจ้งให้ชัดเจนใน Issues ว่าคุณยินดีที่จะจัดหาคอร์ปัสการแปล;
- หากมีกรณีพิเศษ (เช่น การอนุญาตพิเศษ เป็นต้น) โปรดอธิบายด้วย;
- โปรดตรวจสอบให้แน่ใจว่าคอร์ปัสที่คุณให้มีคุณภาพสูง

ภายใต้การอนุญาตของคุณ โปรเจกต์จะเพิ่ม mod ของคุณในรายการ `config/ref_translation_mods.json` ของ mod การแปลอ้างอิง และ pipeline จะซิงค์ข้อความแปลของคุณโดยอัตโนมัติเพื่อใช้เป็นคอร์ปัสอ้างอิงสำหรับ RAG

## 5. การมีส่วนร่วมในการพัฒนา Pipeline และเครื่องมือ

ระบบอัตโนมัติของโปรเจกต์นี้แบ่งออกเป็นสองส่วน:

**โมดูล Pipeline (`src/`, C# / .NET 10):** ประกอบด้วย 15 โมดูลที่ดำเนินการตามลำดับ รับผิดชอบกระบวนการทั้งหมดตั้งแต่การเริ่มต้น SteamCMD, การดาวน์โหลด mod, การแยกข้อความ, การตรวจสอบเนื้อหา, การคำนวณ Embedding, การค้นหา RAG ไปจนถึงการแปล LLM และผลลัพธ์สุดท้าย ดูรายละเอียดที่ [การอ้างอิงทางเทคนิค](../technical_reference/technical_reference_th.md)

**สคริปต์เสริม (.github/):** ใช้สำหรับระบบอัตโนมัติของ GitHub

หากคุณต้องการ:

* แก้ไข Bug ในโมดูล pipeline หรือสคริปต์ที่มีอยู่;
* เพิ่มฟีเจอร์ใหม่หรือโมดูลใหม่ให้กับ pipeline;
* ปรับปรุงประสิทธิภาพหรือโครงสร้างโค้ด;
* ปรับปรุงเทมเพลต prompt หรือกลยุทธ์ RAG;

สามารถทำตามขั้นตอนต่อไปนี้:

1. Fork repository นี้และ clone ไปยังเครื่องของคุณ;
2. สร้าง branch ใหม่จาก branch ล่าสุด;
3. แก้ไขหรือเพิ่มไฟล์ในไดเรกทอรีที่เกี่ยวข้อง:
- แก้ไขโมดูล pipeline → `src/<ชื่อโมดูล>/`;
- แก้ไขสคริปต์ → `scripts/`;
- แก้ไขเทมเพลต Prompt → `src/prompt_templates/`;
4. ก่อนการส่ง โปรดพยายาม:

* รักษารูปแบบโค้ดเดิม;
* เพิ่มความคิดเห็นที่จำเป็น;
* หากเป็นไปได้ ให้แนบการทดสอบหรือคำแนะนำการใช้งานง่ายๆ;
5. ส่งการแก้ไขผ่าน PR และอธิบายในคำอธิบาย:

* วัตถุประสงค์ของการเปลี่ยนแปลง;
* ไดเรกทอรี/โมดูล/สคริปต์ที่อาจได้รับผลกระทบ;
* ว่ามีการเปลี่ยนแปลงที่ทำลายความเข้ากันได้หรือไม่

## 6. ข้อตกลงด้านลิขสิทธิ์และการอนุญาต

> **คำแนะนำ:**
> ข้อตกลงด้านลิขสิทธิ์และการอนุญาตมีไว้เพื่อปกป้องสิทธิ์ที่ชอบด้วยกฎหมายของโครงการ ผู้เขียน ผู้มีส่วนร่วม และผู้เล่น เพื่อหลีกเลี่ยงความเข้าใจผิดที่เกิดจาก "ความเข้าใจโดยปริยาย" หรือ "ค่าเริ่มต้น" โปรดอ่านอย่างละเอียด
> ลิขสิทธิ์และการอนุญาตยึดตามเนื้อหาในไฟล์ README.md ส่วนนี้เป็นเพียงคำอธิบายที่เข้าใจง่ายขึ้น

### 6.1 หลักการพื้นฐาน: คุณสงวนลิขสิทธิ์ พร้อมทั้งอนุญาตให้โครงการใช้งาน

* คุณยังคงมีลิขสิทธิ์ในเนื้อหาที่คุณสร้างขึ้น (คำแปล รูปภาพ สคริปต์/โปรแกรม ฯลฯ);
* แต่หลังจากส่งเนื้อหาเหล่านี้ไปยังคลังนี้และได้รับการยอมรับ (รวม) คุณตกลงที่จะอนุญาตให้ผู้อื่นใช้เนื้อหาเหล่านี้ภายใต้สัญญาอนุญาตแบบโอเพนซอร์ส/การใช้ร่วมกันที่โครงการนี้ใช้

ซึ่งหมายความว่า:

* คุณ **ยังคงสามารถ** ใช้และแสดงผลงานของคุณในที่อื่นต่อไป;
* แต่คุณ **ไม่สามารถ** ขอให้โครงการนี้หรือผู้ใช้ที่ได้มาโดยชอบด้วยกฎหมาย "เพิกถอนการอนุญาต" หรือ "ลบเวอร์ชันประวัติ" หลังจากที่การมีส่วนร่วมของคุณถูกรวมแล้ว

### 6.2 การอนุญาตสำหรับข้อความและรูปภาพ (CC BY-NC-SA 4.0)

สำหรับเนื้อหาต่อไปนี้ที่คุณส่ง:

* คำแปลเกม การปรับปรุง และการพิสูจน์อักษร;
* เอกสารโครงการ ข้อความอธิบาย;
* รูปภาพและทรัพยากรศิลปะที่สร้างขึ้นสำหรับโครงการนี้โดยเฉพาะ;

เมื่อได้รับการยอมรับและรวมเข้าสู่คลังนี้แล้ว จะถือว่าคุณตกลง:

1. เนื้อหาเหล่านี้ได้รับอนุญาตภายใต้สัญญา **แสดงที่มา-ไม่ใช้เพื่อการค้า-อนุญาตแบบเดียวกัน 4.0 ระหว่างประเทศ** (Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International หรือเรียกสั้น ๆ ว่า **CC BY-NC-SA 4.0**);
2. Project Babel และผู้ใช้ทุกคนที่ได้รับเนื้อหาเหล่านี้สามารถ ภายใต้ **การปฏิบัติตามข้อกำหนดของ CC BY-NC-SA 4.0**:
* แบ่งปัน คัดลอก และแจกจ่ายเนื้อหาเหล่านี้;
* แก้ไขและสร้างสรรค์ต่อในกรณีที่ไม่ใช่เชิงพาณิชย์;
3. คุณตกลงว่าภายในขอบเขตที่กฎหมายที่เกี่ยวข้องอนุญาต การอนุญาตนี้เป็นสิทธิ์ **ไม่ผูกขาด ทั่วโลก ปลอดค่าลิขสิทธิ์ และเพิกถอนไม่ได้**;
4. แม้ว่าคุณจะถอนตัวหรือหยุดเข้าร่วมโครงการในอนาคต โครงการนี้ยังคงสามารถใช้และเผยแพร่เนื้อหาที่คุณได้ส่งและถูกรวมตาม CC BY-NC-SA 4.0 ต่อไป

> หากคุณไม่ยอมรับวิธีการอนุญาตข้างต้น โปรดอย่าส่งข้อความหรือรูปภาพที่มีส่วนร่วมมายังโครงการนี้
> หรือติดต่อผู้ดูแลโครงการล่วงหน้าเพื่อยืนยันว่าสามารถทำงานร่วมกันในรูปแบบอื่นได้

### 6.3 การอนุญาตสำหรับสคริปต์และโค้ดเครื่องมือ (GPL-3.0)

สำหรับสิ่งที่คุณส่งและได้รับการยอมรับ:

* สคริปต์อัตโนมัติ;
* เครื่องมือสร้าง/ส่งออก;
* โค้ดโปรแกรมอื่นๆ ที่ใช้ในการจัดการโปรเจกต์นี้;

### 6.4 ลิขสิทธิ์ของผลงานต้นทางและเกมต้นฉบับ

โปรเจกต์นี้เป็นโปรเจกต์**แปลอย่างไม่เป็นทางการ**สำหรับม็อดที่เกี่ยวข้องกับเกม *Project Zomboid*:

* ลิขสิทธิ์ของเกมต้นฉบับและม็อดแต่ละตัวเป็นของผู้สร้าง/ผู้จัดจำหน่ายของพวกเขา;
* โปรเจกต์นี้มุ่งเน้นเฉพาะการแปลข้อความ การปรับปรุงและการรวบรวมทรัพยากรที่เกี่ยวข้องบางส่วน;
* ผู้มีส่วนร่วมในการส่งเนื้อหาควรตรวจสอบให้แน่ใจว่า:
* ไม่คัดลอกข้อความแปลหรือทรัพยากรศิลปะของบุคคลที่สามโดยไม่ได้รับอนุญาต;
* เคารพสิทธิ์ของผู้สร้างต้นฉบับและผู้สร้างม็อด อย่าโพสต์ซ้ำที่มีการละเมิดลิขสิทธิ์;

## 7. การสื่อสารและความร่วมมือ

หากคุณ:

* มีข้อสงสัยเกี่ยวกับข้อกำหนดใบอนุญาต;
* ไม่แน่ใจว่าสามารถส่งเนื้อหาบางส่วนได้หรือไม่;
* ต้องการอนุญาตผลงานของคุณในรูปแบบพิเศษ (เช่น อนุญาตเฉพาะที่ไม่ใช่เชิงพาณิชย์แต่ไม่อนุญาตให้ดัดแปลง ฯลฯ);

คุณสามารถติดต่อผู้ดูแลโปรเจกต์ได้ผ่านช่องทางต่อไปนี้:

* ส่ง Issue เพื่ออภิปราย;
* ช่องทางการติดต่ออื่นๆ ที่ผู้ดูแลเปิดเผยต่อสาธารณะ;

เราจะพยายามหาทางออกที่คำนึงถึงสิทธิของทุกฝ่ายภายใต้เงื่อนไขที่เคารพสิทธิและผลประโยชน์ของทุกฝ่าย เพื่อให้โปรเจกต์พัฒนาไปอย่างมีสุขภาพดี;

## 8. การสนับสนุนทางการเงิน

ระหว่างการดำเนินโปรเจกต์ เนื่องจากมีการเพิ่มม็อดใหม่หรือม็อดเก่าอัปเดตเนื้อหาข้อความ จึงจำเป็นต้องเรียกใช้ LLM API เพื่อแปลอย่างต่อเนื่อง และเพื่อควบคุมพฤติกรรมของ LLM นอกเหนือจากข้อความพื้นฐานของม็อดแล้ว ยังต้องให้เนื้อหา prompt จำนวนมาก (รวมถึง prompt พื้นฐาน กฎการแปล อภิธานศัพท์ ข้อจำกัดอินพุต/เอาต์พุต ผลการค้นหาความหมาย ฯลฯ) ซึ่งเนื้อหาเหล่านี้จะใช้โทเค็นมากกว่าข้อความต้นฉบับอย่างมาก ดังนั้นโปรเจกต์จึงต้องการการสนับสนุนทางการเงิน;

หากคุณยินดีให้การสนับสนุนทางการเงิน โปรดติดต่อผู้ดูแลโปรเจกต์ ขอบคุณมาก!
