**Project Babel - 《僵尸毁灭工程》模组LLM自动翻译项目**에 기여해 주셔서 대단히 감사합니다! 오류 수정, 새로운 기능 추가, 프롬프트 템플릿 작성, 또는 참조 번역 제공 등 무엇이든지 환영합니다!

LLM API를 호출하여 번역하려면 토큰 비용이 발생합니다. 프로젝트의 장기적 안정적 운영을 위해, 여러분의 아낌없는 도움을 부탁드립니다!

> ⚠️ **중요 알림:**
> 이 저장소에 내용을 제출하기 전에 반드시 "저작권 및 라이선스 계약" 섹션을 읽고 이해하시기 바랍니다.
> 제출되어 병합되면 해당 라이선스 조건에 동의한 것으로 간주됩니다.

## 1. 시작하기 전에

먼저 프로젝트의 `README.md`를 읽어 다음 사항을 확인하세요:
- 이 프로젝트의 전체 목표 및 현재 상태
- 일반 플레이어가 이 프로젝트를 사용하는 방법 (자가 테스트용)
- 프로젝트 기술 세부 사항

---

## 2. 어떻게 기여할 수 있나요?

여러분의 관심과 기술에 따라 한 가지 이상의 방법으로 참여할 수 있습니다:

- 대상 언어의 번역 규칙 제공
- 대상 언어의 번역 용어 사전 제공
- 시스템 프롬프트 개선
- 수동 교정된 번역 텍스트 코퍼스 제공
- 파이프라인 모듈(.NET) 및 자동화 스크립트 개선
- 문제 보고, 개선 제안 (Issues에서 설명)
- LLM 호출을 위한 자금 지원

아래에서 주요 기여 시나리오에 대해 설명합니다.

---

## 3. 번역 규칙, 용어 사전 제공, 시스템 프롬프트 개선

파이프라인의 프롬프트 템플릿은 `src/prompt_templates/`에 있으며 구조는 다음과 같습니다:

- `system_prompt_translate_engine.txt`: 전역 번역 엔진 시스템 프롬프트 (모든 언어 공통)
- `<语言代码>/translation_dictionary_<语言代码>.json`: 해당 언어의 용어 사전
- `<语言代码>/translation_schema_<语言代码>.md`: 해당 언어의 번역 규칙 및 스타일 제약

기여 단계:

1. `src/prompt_templates/` 아래에 사용자 언어의 하위 디렉토리를 만들고 용어 사전과 번역 규칙 파일을 추가하세요;
2. 전역 번역 동작을 조정하려면 `system_prompt_translate_engine.txt`를 수정하세요 (모든 언어에 영향을 미침);
3. 로컬 테스트를 통해 효과를 확인합니다.
4. PR을 제출합니다.

---

## 4. 인공 교정 코퍼스 제공

번역 모드 제작자이며, LLM 번역 참고 자료로 번역 코퍼스를 제공하고자 한다면 Issue에 신청해 주세요. 다음 정보를 제공해야 합니다:

- 번역 모드의 Mod ID 및 번역 대상 언어
- 모드 제작자임을 증명하는 번역 모드의 백엔드 페이지 스크린샷
- Issue에서 번역 코퍼스를 제공하겠다고 명시
- 특별한 상황(특별 라이선스 등)이 있을 경우 함께 설명
- 제공하는 코퍼스의 품질이 높은지 확인

귀하의 허가 아래, 프로젝트는 귀하의 모드를 `config/ref_translation_mods.json` 참조 번역 모드 목록에 추가하며, 파이프라인이 자동으로 귀하의 번역 텍스트를 RAG 참조 코퍼스로 동기화합니다.

## 5. 파이프라인 및 도구 개발 기여

본 프로젝트의 자동화는 두 부분으로 나뉩니다:

**파이프라인 모듈 (`src/`, C# / .NET 10)**: SteamCMD 초기화, 모드 다운로드, 텍스트 추출, 내용 검토, 임베딩 계산, RAG 검색, LLM 번역 및 최종 출력까지의 전체 프로세스를 담당하는 15개의 순차 실행 모듈로 구성됩니다. 자세한 내용은 [기술 참조](../technical_reference/technical_reference_ko.md)를 참조하세요.

**보조 스크립트 (`.github/`)**: GitHub 자동화용.

다음과 같은 경우:

* 기존 파이프라인 모듈 또는 스크립트의 버그 수정
* 파이프라인에 새로운 기능 또는 모듈 추가
* 성능 또는 코드 구조 최적화
* prompt 템플릿 또는 RAG 전략 개선

다음 단계를 따르세요:

1. 본 리포지토리를 포크하여 로컬에 클론
2. 최신 브랜치를 기준으로 새 브랜치 생성
3. 해당 디렉토리에서 파일 수정 또는 추가:
- 파이프라인 모듈 수정 → `src/<모듈명>/`
- 스크립트 수정 → `scripts/`
- Prompt 템플릿 수정 → `src/prompt_templates/`
4. 제출 전에 가능한 한:

* 기존 코드 스타일 유지
* 필요한 주석 추가
* 가능하다면 간단한 테스트 또는 사용 설명 첨부
5. PR을 통해 수정 사항을 제출하고, 설명에 다음을 명시하세요:

* 변경 목적;
* 영향을 받을 수 있는 디렉토리 / 모듈 / 스크립트;
* 파괴적 변경(breaking change) 여부.

## 6. 저작권 및 라이선스 규정

> **참고 사항:**
> 저작권 및 라이선스 규정은 프로젝트, 작성자, 기여자 및 플레이어의 정당한 권리를 보호하고, '묵시적 동의'나 '기본값'으로 인한 오해를 방지하기 위한 것입니다. 반드시 주의 깊게 읽어주세요.
> 저작권 및 라이선스는 README.md 파일의 내용을 기준으로 하며, 이 섹션은 더 이해하기 쉬운 설명을 제공합니다.

### 6.1 기본 원칙: 저작권은 유지하되, 프로젝트에 사용을 허가

* 귀하는 자신이 창작한 내용(번역, 이미지, 스크립트/프로그램 등)에 대한 저작권을 여전히 보유합니다;
* 그러나 이러한 내용을 본 프로젝트에 제출하여 채택(병합)된 후에는 본 프로젝트가 채택한 오픈소스/공유 라이선스 계약에 따라 타인이 이러한 내용을 사용할 수 있도록 허가하는 데 동의합니다.

즉, 다음을 의미합니다:

* 귀하는 **여전히** 다른 곳에서 자신의 작품을 계속 사용하고 전시할 수 있습니다;
* 그러나 귀하는 기여가 병합된 후에 본 프로젝트 또는 이미 합법적으로 작품을 획득한 사용자에게 '허가 철회'나 '이전 버전 삭제'를 요구할 **수 없습니다**.

### 6.2 텍스트 및 이미지 등 콘텐츠의 라이선스 (CC BY-NC-SA 4.0)

귀하가 제출하는 다음 내용에 대해:

* 게임 텍스트 번역, 다듬기 및 교정 내용;
* 프로젝트 문서, 설명 텍스트;
* 본 프로젝트를 위해 특별히 제작된 이미지, 아트 리소스;

본 저장소에 채택되어 병합되면, 귀하는 다음에 동의하는 것으로 간주됩니다:

1. 이러한 내용은 **저작자표시-비영리-동일조건변경허락 4.0 국제**(Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International, 약칭 **CC BY-NC-SA 4.0**) 라이선스로 제공됩니다;
2. Project Babel 및 해당 콘텐츠를 획득한 모든 사용자는 **CC BY-NC-SA 4.0 조항을 준수**하는 조건下:
* 이러한 내용을 공유, 복사, 재배포할 수 있습니다;
* 비상업적 용도로 수정 및 2차 창작할 수 있습니다;
3. 귀하는 관련 법률이 허용하는 범위 내에서 해당 라이선스가 **비독점적, 전 세계적, 로열티-프리(무료), 취소 불가능**한 허가임에 동의합니다;
4. 귀하가 향후 본 프로젝트에서 탈퇴하거나 참여를 중단하더라도, 본 프로젝트는 귀하가 제출하여 병합된 관련 콘텐츠를 계속해서 CC BY-NC-SA 4.0에 따라 사용 및 재배포할 수 있습니다.

> 위 라이선스 방식을 수락하지 않는 경우, 본 프로젝트에 텍스트나 이미지 종류의 기여를 제출하지 말아 주십시오.

### 6.3 스크립트 및 도구 코드의 라이선스 (GPL-3.0)

귀하가 제출하여 채택된 다음에 대해:

* 자동화 스크립트;
* 빌드/내보내기 도구;
* 본 한글화 프로젝트를 처리하는 기타 프로그램 코드;

특별한 언급이 없는 한, 다음에 동의하는 것으로 간주됩니다:

1. 코드는 **GPL-3.0**(GNU 일반 공중 사용 허가서 제3판)에 따라 라이선스됩니다;
2. 프로젝트 유지관리자는 GPL-3.0이 허용하는 범위 내에서 이를 수정, 병합, 배포할 수 있습니다;
3. GPL-3.0의 조항을 준수하는 한 동일한 코드를 기반으로 다른 프로젝트를 계속 진행할 수도 있습니다.

라이선스 충돌을 방지하기 위해 다음을 권장합니다:

* 확인되지 않은 상태에서 **GPL-3.0과 호환되지 않는** 타사 코드를 도입하지 마십시오;
* 제3자 라이브러리를 참조해야 하는 경우 PR에서 출처와 라이선스를 명확히 설명하고 호환성을 확인하십시오.

### 6.4 상위 작품 및 원본 게임 저작권

본 프로젝트는 《좀비 멸망 공정》(Project Zomboid) 관련 모드의 **비공식 번역** 프로젝트입니다:

* 원본 게임 및 각 모드 자체의 저작권은 각 저작자/배포자에게 있습니다;
* 본 프로젝트는 텍스트 번역, 다듬기 및 일부 관련 리소스에 대해서만 창작 및 정리를 수행합니다;
* 기여자는 내용을 제출할 때 다음을 확인해야 합니다:
* 승인되지 않은 타사 한글화 텍스트 또는 그래픽 리소스를 직접 복사하지 않음;
* 원저작자와 모드 제작자의 권리를 존중하고, 저작권을 침해하는 전재를 하지 않음.

## 7. 의사소통 및 협업

다음에 대해 문의가 있다면:

* 라이선스 조항에 질문이 있는 경우;
* 특정 내용을 기여해도 되는지 확실하지 않은 경우;
* 귀하의 저작물을 특별한 방식으로 라이선스하고자 하는 경우(예: 비상업적 용도만 허용하고 개작은 허용하지 않음 등);

다음 방법으로 프로젝트 유지관리자에게 연락해 주십시오:

* Issue를 제출하여 논의;
* 기타 유지관리자가 공개적으로 제공하는 연락 방법.

당사는 각 당사자의 권리를 존중하는 전제 하에 프로젝트의 건전한 발전을 고려한 해결책을 찾도록 노력하겠습니다.

## 8. 자금 지원

프로젝트 운영 중, 새로운 모드 추가, 기존 모드의 텍스트 업데이트 등으로 인해 LLM API를 지속적으로 호출하여 번역해야 합니다. 또한 LLM의 동작을 제어하기 위해 기본 모드 텍스트 외에도 많은 양의 프롬프트 내용(기본 프롬프트, 번역 규칙, 용어집, 입출력 제약, 의미 검색 결과 등)이 필요하며, 이러한 내용은 원본 텍스트보다 훨씬 많은 토큰을 소모합니다. 따라서 프로젝트에는 자금 지원이 필요합니다.

자금 지원을 원하시면 프로젝트 유지관리자에게 연락해 주십시오. 매우 감사합니다!
