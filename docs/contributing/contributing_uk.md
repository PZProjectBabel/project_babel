Дякуємо, що ви бажаєте зробити внесок у **Project Babel - проект автоматичного перекладу LLM для модів Project Zomboid**! Чи то виправлення помилки, додавання нової функції, написання шаблону підказки чи надання еталонного перекладу!

Виклик LLM API для перекладу потребує оплати токенів. Щоб проект міг працювати стабільно в довгостроковій перспективі, сподіваємося на вашу щедру допомогу!

> ⚠️ **Важливе зауваження:**
> Перед поданням будь-якого вмісту до цього сховища обов'язково прочитайте та зрозумійте розділ «Угода про авторські права та ліцензування».
> Після подання та злиття вашого внеску це вважається вашою згодою з відповідними ліцензійними умовами.

## 1. Перш ніж почати

Спочатку прочитайте `README.md` проекту, щоб дізнатися:
- Загальна мета проекту та поточний стан;
- Як звичайні гравці можуть використовувати цей проект (для самоперевірки);
- Технічні деталі проекту.

## 2. Як я можу зробити внесок?

Ви можете обрати один або кілька способів участі, виходячи зі своїх інтересів і навичок:

- Надати правила перекладу для цільової мови
- Надати словник термінів перекладу для цільової мови
- Покращити підказки системи
- Надати корпус перекладених текстів після ручної вичитки
- Покращити модулі конвеєра (.NET) та скрипти автоматизації
- Повідомляти про проблеми, пропонувати покращення (в Issues)
- Надати фінансову підтримку для викликів LLM

Нижче наведено короткий опис основних сценаріїв внеску.

---

## 3. Надання правил перекладу, словника термінів, покращення системних підказок

Шаблони підказок конвеєра знаходяться в `src/prompt_templates/`, структура наступна:

- `system_prompt_translate_engine.txt`: Системна підказка глобального рушія перекладу (спільна для всіх мов);
- `<мовний_код>/translation_dictionary_<мовний_код>.json`: Словник термінів для цієї мови;
- `<мовний_код>/translation_schema_<мовний_код>.md`: Правила перекладу та стилістичні обмеження для цієї мови.

Кроки для внеску:

1. Створіть підкаталог для вашої мови в `src/prompt_templates/`, додайте словник термінів і файли правил перекладу;
2. Якщо потрібно налаштувати глобальну поведінку перекладу, змініть `system_prompt_translate_engine.txt` (зверніть увагу, що це впливає на всі мови);
3. локальне тестування підтверджує ефективність;
4. надіслати PR.

---

## 4. Надання вичитаних корпусів

Якщо ви є автором перекладного моду і бажаєте надати свої корпуси перекладів як довідку для LLM, створіть запит в Issue. Вам потрібно надати такі матеріали:

- Mod ID вашого перекладного моду та цільова мова перекладу;
- скріншот сторінки адміністрування вашого перекладного моду для підтвердження авторства;
- у Issue чітко зазначити, що ви готові надати корпуси перекладів;
- якщо є особливі умови (спеціальна ліцензія тощо), додатково поясніть;
- переконайтеся, що надані корпуси є якісними.

За вашою ліцензією проект додасть ваш мод до списку `config/ref_translation_mods.json` довідкових перекладних модів, а конвеєр автоматично синхронізуватиме ваш переклад як довідковий корпус RAG.

## 5. Внесок у конвеєр та розробку інструментів

Автоматизація проекту поділяється на дві частини:

**Конвеєрний модуль (`src/`, C# / .NET 10)** : містить 15 модулів, що виконуються послідовно, плюс 2 незалежні модулі (`WorkshopMonitor` – виявлення модів, `DocGenerator` – генератор документації), які відповідають за повний процес від ініціалізації SteamCMD, завантаження модів, вилучення тексту, перевірку вмісту, обчислення Embedding, пошук RAG до перекладу LLM і фінального виводу. Детальніше див. [Технічне посилання](../technical_reference/technical_reference_uk.md).

**Допоміжні скрипти (`.github/`)**: використовуються для автоматизації GitHub.

Якщо ви бажаєте:

* виправити помилки в існуючих модулях конвеєра або скриптах;
* додати нові функції або модулі до конвеєра;
* оптимізувати продуктивність або структуру коду;
* покращити шаблони prompt або стратегію RAG;

виконайте такі кроки:

1. Fork цього репозиторію та клонуйте його локально;
2. створіть нову гілку на основі останньої;
3. у відповідній директорії змініть або додайте файли:
- зміна модуля конвеєра → `src/<назва модуля>/`;
- Зміна CI робочого процесу → `.github/workflows/`;
- зміна шаблонів Prompt → `src/prompt_templates/`;
4. перед надсиланням бажано:

* зберігати оригінальний стиль коду;
* додавати необхідні коментарі;
* за можливості додати прості тести або інструкцію з використання;
5. Надішліть зміни через PR і в описі зазначте:

* мету змін;
* каталоги / модулі / скрипти, на які це може вплинути;
* чи містить зміни, що порушують зворотну сумісність.

* Ви **все ще можете** продовжувати використовувати та демонструвати свої роботи в інших місцях;

## 8. Фінансова підтримка

Під час роботи проєкту, через додавання нових модів та оновлення тексту старих модів, потрібно постійно викликати LLM API для перекладу. Для обмеження поведінки LLM, окрім основного тексту модів, необхідно надавати велику кількість змісту підказок (включаючи базові підказки, правила перекладу, глосарії, обмеження введення/виведення, результати семантичного пошуку тощо), які споживають значно більше токенів, ніж оригінальний текст. Тому проєкт потребує фінансової підтримки.

Якщо ви бажаєте надати фінансову підтримку, зв'яжіться з супроводжувачами проєкту. Велике дякую!
