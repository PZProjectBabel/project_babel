Дякуємо за вашу готовність зробити внесок у **Project Babel — проект автоматичного перекладу модів Project Zomboid за допомогою LLM**! Чи то виправлення помилки, додавання функції, написання шаблонів промптів або надання еталонних перекладів — важливий кожен внесок!

## Як я можу зробити внесок?

Ви можете вибрати один або кілька способів участі залежно від ваших інтересів та навичок:

- Надати правила перекладу для цільової мови

- Покращити системні промпти

Нижче наведено пояснення до основних сценаріїв участі.

## Надання правил перекладу, термінологічних словників та покращення системних промптів

Шаблони промптів пайплайну знаходяться в `src/prompt_templates/` з наступною структурою:

- `system_prompt_translate_engine.txt`: глобальний системний промпт рушія перекладу (спільний для всіх мов);
- `<код_мови>/translation_dictionary_<код_мови>.json`: термінологічний словник для цієї мови;
- `<код_мови>/translation_schema_<код_мови>.md`: правила перекладу та стильові обмеження для цієї мови.

Кроки для внесення внеску:

1. Створіть підкаталог у `src/prompt_templates/` для вашої мови та додайте файли словника та правил перекладу;
2. Якщо потрібно скоригувати глобальну поведінку перекладу, змініть `system_prompt_translate_engine.txt` (зверніть увагу: це впливає на всі мови);
3. Протестуйте локально, щоб підтвердити результати;
4. Надішліть PR.

---

## Надання вручну вивірених корпусів

Якщо ви автор моду перекладу та готові надати свій перекладацький корпус як еталон для LLM, будь ласка, подайте заявку через Issue. Вам потрібно надати таку інформацію:

- Mod ID вашого моду перекладу та цільову мову;
- Скріншот сторінки керування вашим модом перекладу для підтвердження авторства;
- Чітку заяву в Issue про вашу готовність надати перекладацький корпус;
- За наявності особливих обставин (спеціальна ліцензія тощо), будь ласка, поясніть їх;
- Будь ласка, переконайтеся, що наданий корпус має високу якість.

З вашого дозволу проект додасть ваш мод до списку еталонних перекладацьких модів `config/ref_translation_mods.json`, і пайплайн автоматично синхронізує ваші перекладені тексти як еталонні корпуси RAG.

## Внесок у розробку пайплайну та інструментів

Автоматизація в цьому проекті поділена на дві частини:

**Модулі пайплайну (`src/`, C# / .NET 10)**: Містить 15 послідовно виконуваних модулів, відповідальних за повний робочий процес від завантаження модів, вилучення тексту, перевірки контенту, обчислення ембедингів, пошуку RAG до перекладу LLM та фінального виводу. Докладніше див. у [технічному довіднику](../technical_reference/technical_reference_uk.md).

**Допоміжні скрипти (`.github/`)**: Використовуються для автоматизації GitHub.

Якщо ви хочете:

* Виправити помилки в існуючих модулях пайплайну або скриптах;
* Додати нові функції або модулі до пайплайну;
* Оптимізувати продуктивність або структуру коду;
* Покращити шаблони промптів або стратегії RAG;

Ви можете дотримуватися цих кроків:

1. Зробіть форк цього репозиторію та клонуйте його локально;
2. Створіть нову гілку з останньої гілки;
3. Змініть або додайте файли у відповідних каталогах:
   - Зміни модулів пайплайну → `src/<назва_модуля>/`;
   - Зміни скриптів → `scripts/`;
   - Зміни шаблонів промптів → `src/prompt_templates/`;
4. Перед надсиланням по можливості:

   * Зберігайте існуючий стиль коду;
   * Додавайте необхідні коментарі;
   * Якщо можливо, додайте прості тести або інструкції з використання;
5. Надішліть зміни через PR, вказавши в описі:

   * Мета змін;
   * Каталоги / модулі / скрипти, які можуть бути порушені;
   * Чи мають місце критичні зміни.

Якщо ви готові надати фінансову підтримку, будь ласка, зв''яжіться з мейнтейнерами проекту. Велике спасибі!
