## どのような貢献ができますか？

興味やスキルに応じて、以下の方法から 1 つ以上を選んで参加できます：

- 対象言語の翻訳ルールの提供
- 対象言語の用語辞書の提供
- システムプロンプトの改善
- 人手で校正した翻訳コーパスの提供
- パイプラインモジュール（.NET）と自動化スクリプトの改善
- Issue での問題報告・改善提案
- LLM API 呼び出しのための資金提供

以下、主な貢献シナリオについて説明します。

## 翻訳ルール・用語辞書の提供、システムプロンプトの改善

パイプラインのプロンプトテンプレートは `src/prompt_templates/` にあり、以下の構成になっています：

- `system_prompt_translate_engine.txt`：全言語共通の翻訳エンジンシステムプロンプト；
- `<言語コード>/translation_dictionary_<言語コード>.json`：当該言語の用語辞書；
- `<言語コード>/translation_schema_<言語コード>.md`：当該言語の翻訳ルールとスタイル制約。

貢献の手順：

1. `src/prompt_templates/` の下に言語用のサブディレクトリを作成し、用語辞書と翻訳ルールファイルを追加します；
2. 全体的な翻訳動作を調整する必要がある場合は、`system_prompt_translate_engine.txt` を修正します（全言語に影響することに注意）；
3. ローカルでテストして効果を確認します；
4. PR を提出します。

---

## 人手校正コーパスの提供

翻訳 MOD の作者で、ご自身の翻訳コーパスを LLM の翻訳参考として提供いただける場合は、Issue で申請してください。以下の情報が必要です：

- 翻訳 MOD の Mod ID と対象言語；
- 翻訳 MOD の管理ページのスクリーンショット（作者であることの証明）；
- Issue 内で翻訳コーパス提供の意思を明示；
- 特別な事情（特別ライセンスなど）があれば併せて説明；
- 提供するコーパスが高品質であることをご確認ください。

ご承認いただくと、プロジェクトはあなたの MOD を `config/ref_translation_mods.json` の参考翻訳 MOD リストに追加し、パイプラインが自動的に翻訳テキストを RAG 参考コーパスとして同期します。

## パイプラインとツール開発への貢献

本プロジェクトの自動化は 2 つの部分で構成されています：

**パイプラインモジュール（`src/`、C# / .NET 10）**：15 個の順次実行モジュールで構成され、MOD のダウンロード、テキスト抽出、コンテンツ審査、Embedding 計算、RAG 検索から LLM 翻訳、最終出力までの完全なワークフローを担当します。詳細は [技術リファレンス](../technical_reference/technical_reference_ja.md) をご参照ください。

**補助スクリプト（`.github/`）**：GitHub の自動化に使用されます。

もし以下のことを希望される場合：

* 既存のパイプラインモジュールやスクリプトのバグ修正；
* パイプラインへの新機能や新モジュールの追加；
* パフォーマンスやコード構造の最適化；
* プロンプトテンプレートや RAG 戦略の改善；

以下の手順で進めてください：

1. このリポジトリを Fork してローカルにクローンします；
2. 最新ブランチから新しいブランチを作成します；
3. 対応するディレクトリでファイルを修正または追加します：
   - パイプラインモジュールの変更 → `src/<モジュール名>/`；
   - スクリプトの変更 → `scripts/`；
   - プロンプトテンプレートの変更 → `src/prompt_templates/`；
4. 提出前に、できるだけ以下を心がけてください：

   * 既存のコードスタイルを維持する；
   * 必要なコメントを追加する；
   * 可能であれば、簡単なテストや使用説明を添付する；
5. PR で変更を提出し、説明に以下を記載してください：

   * 変更の目的；
   * 影響を受ける可能性のあるディレクトリ / モジュール / スクリプト；
   * 破壊的変更の有無。

## 資金支援

プロジェクトの運営において、新規 MOD の追加や既存 MOD のテキスト更新などにより、継続的に LLM API を呼び出して翻訳する必要があります。LLM の動作を制約するために、ベースとなる MOD テキストに加えて、大量のプロンプト内容（基本プロンプト、翻訳ルール、用語表、入出力制約、意味検索結果など）が必要となり、これらは元のテキストをはるかに超えるトークンを消費します。そのため、プロジェクトには資金支援が必要です。

資金支援をご希望の場合は、プロジェクトメンテナまでご連絡ください。ありがとうございます！
