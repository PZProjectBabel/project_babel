## Как я могу внести вклад?

Вы можете выбрать один или несколько способов участия в зависимости от ваших интересов и навыков:

- Предоставить правила перевода для целевого языка
- Предоставить терминологический словарь для целевого языка
- Улучшить системные промпты
- Предоставить вручную выверенные переводческие корпусы
- Улучшить модули пайплайна (.NET) и скрипты автоматизации
- Сообщать о проблемах и предлагать улучшения (через Issues)
- Оказать финансовую поддержку для вызовов API LLM

Ниже приведены пояснения к основным сценариям участия.

## Предоставление правил перевода, терминологических словарей и улучшение системных промптов

Шаблоны промптов пайплайна находятся в src/prompt_templates/ со следующей структурой:

- system_prompt_translate_engine.txt: глобальный системный промпт движка перевода (общий для всех языков);
- <код_языка>/translation_dictionary_<код_языка>.json: терминологический словарь для этого языка;
- <код_языка>/translation_schema_<код_языка>.md: правила перевода и стилевые ограничения для этого языка.

Шаги для внесения вклада:

1. Создайте подкаталог в src/prompt_templates/ для вашего языка и добавьте файлы словаря и правил перевода;
2. Если необходимо скорректировать глобальное поведение перевода, измените system_prompt_translate_engine.txt (обратите внимание: это влияет на все языки);
3. Протестируйте локально, чтобы подтвердить результаты;
4. Отправьте PR.

## Предоставление вручную выверенных корпусов

Если вы автор мода-перевода и готовы предоставить свой переводческий корпус в качестве эталона для LLM, пожалуйста, подайте заявку через Issue. Вам необходимо предоставить следующую информацию:

- Mod ID вашего мода-перевода и целевой язык;
- Скриншот страницы управления вашим модом-переводом для подтверждения авторства;
- Чёткое заявление в Issue о вашей готовности предоставить переводческий корпус;
- При наличии особых обстоятельств (специальная лицензия и т.д.), пожалуйста, объясните их;
- Пожалуйста, убедитесь, что предоставляемый корпус имеет высокое качество.

С вашего разрешения проект добавит ваш мод в список эталонных переводческих модов config/ref_translation_mods.json, и пайплайн автоматически синхронизирует ваши переведённые тексты как эталонные корпусы RAG.

## Вклад в разработку пайплайна и инструментов

Автоматизация в этом проекте разделена на две части:

**Модули пайплайна (src/, C# / .NET 10)**: Содержит 15 последовательно выполняемых модулей, отвечающих за полный рабочий процесс от загрузки модов, извлечения текста, проверки контента, вычисления эмбеддингов, поиска RAG до перевода LLM и финального вывода. Подробнее см. в [техническом справочнике](../technical_reference/technical_reference_ru.md).

**Вспомогательные скрипты (.github/)**: Используются для автоматизации GitHub.

Если вы хотите:

* Исправить ошибки в существующих модулях пайплайна или скриптах;
* Добавить новые функции или модули в пайплайн;
* Оптимизировать производительность или структуру кода;
* Улучшить шаблоны промптов или стратегии RAG;

Вы можете следовать этим шагам:

1. Сделайте форк этого репозитория и клонируйте его локально;
2. Создайте новую ветку от последней ветки;
3. Измените или добавьте файлы в соответствующих каталогах:
   - Изменения модулей пайплайна → src/<имя_модуля>/;
   - Изменения скриптов → scripts/;
   - Изменения шаблонов промптов → src/prompt_templates/;
4. Перед отправкой по возможности:

   * Сохраняйте существующий стиль кода;
   * Добавляйте необходимые комментарии;
   * Если возможно, приложите простые тесты или инструкции по использованию;
5. Отправьте изменения через PR, указав в описании:

   * Цель изменений;
   * Каталоги / модули / скрипты, которые могут быть затронуты;
   * Имеют ли место критические изменения.

## Финансовая поддержка

В ходе работы проекта, в связи с добавлением новых модов и обновлением текстов существующих модов, необходимо постоянно вызывать API LLM для перевода. Для ограничения поведения LLM, помимо базовых текстов модов, требуется большое количество промпт-контента (включая базовые промпты, правила перевода, терминологические таблицы, ограничения ввода/вывода, результаты семантического поиска и т.д.), что потребляет значительно больше токенов, чем исходные тексты. Поэтому проекту необходима финансовая поддержка.

Если вы готовы оказать финансовую поддержку, пожалуйста, свяжитесь с мейнтейнерами проекта. Большое спасибо!
