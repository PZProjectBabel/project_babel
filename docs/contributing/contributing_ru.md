Большое спасибо за желание внести вклад в **Project Babel - проект автоматического перевода модов для игры Project Zomboid с помощью LLM**! Независимо от того, исправляете ли вы ошибку, добавляете новую функцию, пишете шаблоны промптов или предоставляете эталонные переводы!

Вызов LLM API для перевода требует оплаты токенов. Чтобы проект мог стабильно работать в долгосрочной перспективе, надеемся на вашу щедрую поддержку!

> ⚠️ **Важное напоминание:**
> Перед отправкой любого содержимого в этот репозиторий обязательно прочитайте и поймите раздел «Соглашение об авторских правах и лицензировании».
> Как только ваш вклад будет отправлен и принят (слит), это считается вашим согласием с соответствующими лицензионными условиями.

## 2. Как я могу внести вклад?

Вы можете выбрать один или несколько способов участия в зависимости от ваших интересов и навыков:

- Предоставить правила перевода для целевого языка
- Предоставить словарь терминов перевода для целевого языка
- Улучшить системные промпты
- Предоставить выверенные вручную тексты переводов (корпус)
- Улучшить модули конвейера (.NET) и скрипты автоматизации
- Сообщать о проблемах и предлагать улучшения (в Issues)
- Оказать финансовую поддержку для вызовов LLM

Ниже приведены пояснения по основным сценариям вклада.

## 3. Предоставление правил перевода, словарей терминов, улучшение системных промптов

Шаблоны промптов конвейера находятся в `src/prompt_templates/`, структура следующая:

- `system_prompt_translate_engine.txt`: глобальный системный промпт движка перевода (общий для всех языков);
- `<языковой_код>/translation_dictionary_<языковой_код>.json`: словарь терминов для этого языка;
- `<языковой_код>/translation_schema_<языковой_код>.md`: правила перевода и стилистические ограничения для этого языка.

Шаги для внесения вклада:

1. Создайте подкаталог для вашего языка в `src/prompt_templates/`, добавьте словарь терминов и файл с правилами перевода;
2. Если необходимо изменить глобальное поведение перевода, измените `system_prompt_translate_engine.txt` (обратите внимание, что это повлияет на все языки);
3. Локальное тестирование для подтверждения эффекта;
4. Отправьте PR.

## 4. Предоставление корпуса для ручной вычитки

Если вы разработчик переводного мода и готовы предоставить свои переводы в качестве эталона для LLM, подайте заявку в Issue. Вам потребуется предоставить следующие материалы:

- Mod ID вашего переводного мода и целевой язык перевода;
- Скриншот страницы администрирования вашего переводного мода, чтобы подтвердить, что вы являетесь автором;
- Чётко укажите в Issue, что вы готовы предоставить корпус перевода;
- Если есть особые обстоятельства (особое лицензирование и т.п.), укажите их дополнительно;
- Убедитесь, что предоставляемый корпус имеет высокое качество.

С вашего разрешения проект добавит ваш мод в список эталонных переводных модов `config/ref_translation_mods.json`, и конвейер автоматически синхронизирует ваши переводы как эталонный корпус для RAG.

## 5. Вклад в разработку конвейера и инструментов

Автоматизация этого проекта разделена на две части:

**Модуль конвейера (`src/`, C# / .NET 10)**: содержит 15 последовательно выполняемых модулей, отвечающих за полный процесс от инициализации SteamCMD, загрузки модов, извлечения текста, проверки содержимого, вычисления эмбеддингов, поиска RAG до перевода LLM и финального вывода. Подробнее см. [Техническая справка](../technical_reference/technical_reference_ru.md).

**Вспомогательные скрипты (`.github/`)**: для автоматизации GitHub.

Если вы хотите:

* Исправить ошибки в существующих модулях конвейера или скриптах;
* Добавить новые функции или модули в конвейер;
* Оптимизировать производительность или структуру кода;
* Улучшить шаблоны prompt или стратегию RAG;

Вы можете действовать следующим образом:

1. Форкните этот репозиторий и клонируйте его локально;
2. Создайте новую ветку на основе последней ветки;
3. Измените или добавьте файлы в соответствующих каталогах:
- Изменения модулей конвейера → `src/<имя_модуля>/`;
- Изменения скриптов → `scripts/`;
- Изменения шаблонов Prompt → `src/prompt_templates/`;
4. Перед отправкой постарайтесь:

* Сохранять исходный стиль кода;
* Добавлять необходимые комментарии;
* При возможности приложить простые тесты или инструкции по использованию;
5. Отправьте изменения через PR и укажите в описании:

* цель изменений;
* затрагиваемые каталоги/модули/скрипты;
* касается ли это критических изменений.

## 8. Финансовая поддержка

В ходе работы проекта из-за добавления новых модов, обновления текстового содержимого старых модов и т.д. требуется постоянный вызов API LLM для перевода. Для контроля поведения LLM, помимо базового текста модов, необходимо предоставлять большое количество подсказок (включая базовые подсказки, правила перевода, глоссарий, ограничения ввода/вывода, результаты семантических запросов и т.д.), что потребляет гораздо больше токенов, чем исходный текст. Поэтому проект нуждается в финансовой поддержке.

Если вы готовы оказать финансовую поддержку, свяжитесь с сопровождающими проекта. Большое спасибо!
