[h1]Project Babel - Автоматический ИИ-перевод множества модов на разные языки[/h1]

[h2]Один мод для локализации всего[/h2]
[hr]
[b]Project Babel[/b] - это проект [b]автоматического многоязычного перевода[/b] модов для Project Zomboid Build 42. Подпишитесь и включите этот мод, чтобы получать переводы популярных модов Steam Workshop на поддерживаемые языки. Проект уже оплатил расходы на вызовы больших языковых моделей, поэтому игроки могут подписаться без дополнительной платы.

Полностью автоматизированный конвейер перевода:
[list]
[*]Ежедневно отслеживает публикации и обновления модов Steam Workshop;
[*]Извлекает локализационные тексты модов еженедельными пакетами;
[*]Проверяет содержимое модов;
[*]Автоматически объединяет терминологию, эталонные переводы и векторный поиск (RAG) для формирования контекста;
[*]Еженедельно вызывает LLM API для пакетного перевода.
[/list]

[b]Как использовать[/b]
[list=1]
[*]Подпишитесь на этот мод.
[*]Включите этот мод в менеджере модов игры.
[*]Поместите этот мод перевода после функциональных модов, желательно в конце порядка загрузки, чтобы его переводы имели приоритет.
[*]Если вы подписаны на несколько модов перевода, переводящих один и тот же функциональный мод, мод перевода, загружаемый позже, заменит одноимённые переводы из модов, загруженных ранее.
[/list]

[h2]Прогресс проекта[/h2]
[hr]
В настоящее время поддерживается более 1300 модов. Проект ежедневно автоматически обнаруживает и включает старые моды Steam Workshop с более чем 500 подписчиками, а также непрерывно проверяет обновления включённых модов. Некоторые моды пока не включены из-за проверки содержимого, отсутствия извлекаемого текста или по другим причинам.

При наличии средств на аккаунте LLM API автоматизация каждую пятницу вечером еженедельно переводит весь новый и изменённый текст.

Подробный прогресс смотрите в репозитории GitHub.
