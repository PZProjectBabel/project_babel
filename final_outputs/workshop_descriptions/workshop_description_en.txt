[h1]Project Babel - Multi-Mod, Multilingual AI Auto-Translation[/h1]

[h2]One Mod to Localize All[/h2]
[hr]
[b]Project Babel[/b] is a [b]multilingual automatic translation[/b] project for Project Zomboid Build 42 mods. Subscribe to and enable this mod to receive translations for popular Steam Workshop mods in supported languages. The project has already covered the cost of large language model calls, so players can subscribe at no additional cost.

Fully automated translation pipeline:
[list]
[*]Monitors Steam Workshop mod releases and updates daily;
[*]Extracts mod localization text in weekly batches;
[*]Reviews mod content;
[*]Automatically combines terminology, reference translations, and vector retrieval (RAG) to build context;
[*]Calls the LLM API weekly for batch translation.
[/list]

[b]How to Use[/b]
[list=1]
[*]Subscribe to this mod.
[*]Enable this mod in the game's mod manager.
[*]Place this translation mod after the functional mods, preferably at the bottom of the load order, so its translations take priority.
[*]If you subscribe to multiple translation mods that translate the same functional mod, the translation mod loaded later will override identically named translations from mods loaded earlier.
[/list]

[h2]Project Progress[/h2]
[hr]
Currently supports 1,300+ mods. The project automatically detects and includes historical Steam Workshop mods with more than 500 subscribers every day, and continuously checks included mods for updates. Some mods are not yet included due to content review, unavailable extractable text, or other reasons.

Provided that the LLM API account remains funded, automation translates all newly added and changed text in a weekly batch every Friday night.

See the GitHub repository for detailed progress.
