[h1]Project Babel - 多模組、多語種 AI 自動翻譯[/h1]

[h2]一個模組，本地化一切[/h2]
[hr]
[b]Project Babel[/b] 是一個面向《僵屍毀滅工程》Build 42 模組的[b]多語種自動翻譯[/b]專案。訂閱並啟用本模組後，可為創意工坊熱門模組提供支援語言的翻譯文字。專案已支付大型語言模型的呼叫費用，玩家訂閱後無須額外付費。

全自動翻譯流水線：
[list]
[*]每日監測創意工坊模組上架、更新；
[*]每週集中提取模組本地化文字；
[*]模組內容審核；
[*]自動結合術語、參考譯文和向量檢索（RAG）產生上下文；
[*]每週呼叫 LLM API 集中翻譯。
[/list]

[b]使用說明[/b]
[list=1]
[*]訂閱本模組。
[*]在遊戲的模組管理中啟用本模組。
[*]翻譯模組請置於功能模組之後，建議放在載入順序底部，以確保翻譯文字優先覆蓋。
[*]如果你訂閱了多個翻譯模組，且多個翻譯模組都翻譯了同一個功能模組的文字，則後載入的翻譯模組會覆蓋先載入模組的同名翻譯文字。
[/list]

[h2]專案進度[/h2]
[hr]
目前支援 1,300+ 個模組。專案每天自動偵測並收錄訂閱數大於 500 的工坊歷史模組，也會持續偵測已收錄模組的更新。部分模組因內容審核、缺少可提取文字或其他原因暫未包含。

如果 LLM API 帳戶仍有資金，自動化指令碼會在每週五晚集中自動翻譯全部新增文字和變動文字。

詳細進度請見 GitHub 儲存庫。
