[h1]Project Babel - 다중 모드, 다국어 AI 자동 번역[/h1]

[h2]하나의 모드로 모든 것을 현지화[/h2]
[hr]
[b]Project Babel[/b]은 Project Zomboid Build 42 모드를 위한 [b]다국어 자동 번역[/b] 프로젝트입니다. 이 모드를 구독하고 활성화하면 지원 언어로 인기 Steam Workshop 모드의 번역을 이용할 수 있습니다. 대규모 언어 모델 호출 비용은 프로젝트에서 이미 부담하므로, 플레이어는 추가 비용 없이 구독할 수 있습니다.

완전 자동화된 번역 파이프라인:
[list]
[*]Steam Workshop 모드의 출시와 업데이트를 매일 모니터링합니다;
[*]매주 모드 현지화 텍스트를 일괄 추출합니다;
[*]모드 콘텐츠를 검토합니다;
[*]용어집, 참조 번역 및 벡터 검색(RAG)을 자동으로 결합하여 문맥을 구성합니다;
[*]매주 LLM API를 호출하여 일괄 번역합니다.
[/list]

[b]사용 방법[/b]
[list=1]
[*]이 모드를 구독합니다.
[*]게임의 모드 관리자에서 이 모드를 활성화합니다.
[*]번역 모드는 기능 모드 뒤에 배치하고, 번역이 우선 적용되도록 가급적 로드 순서 맨 아래에 배치하세요.
[*]같은 기능 모드를 번역하는 여러 번역 모드를 구독한 경우, 나중에 로드되는 번역 모드가 먼저 로드된 모드의 동일한 이름의 번역을 덮어씁니다.
[/list]

[h2]프로젝트 진행 상황[/h2]
[hr]
현재 1,300개 이상의 모드를 지원합니다. 프로젝트는 구독자 수가 500명을 초과하는 과거 Steam Workshop 모드를 매일 자동으로 감지하고 포함하며, 포함된 모드의 업데이트도 지속적으로 확인합니다. 일부 모드는 콘텐츠 검토, 추출 가능한 텍스트 부족 또는 기타 이유로 아직 포함되지 않았습니다.

LLM API 계정에 자금이 유지되는 경우, 자동화는 매주 금요일 밤에 새로 추가되거나 변경된 모든 텍스트를 주간 일괄 번역합니다.

자세한 진행 상황은 GitHub 저장소에서 확인하세요.
